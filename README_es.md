## 🔍 Explicación de los tipos de proxy

| Tipo | Descripción | Mejor para |
|------|-------------|----------|
| **HTTP** | Proxies web estándar | Navegación general, extracción de datos |
| **HTTPS/SSL** | Proxies HTTP encriptados | Conexiones seguras, sitios HTTPS |
| **SOCKS4** | Proxies TCP de bajo nivel | Túneles rápidos, aplicaciones antiguas |
| **SOCKS5** | Proxies avanzados con soporte de autenticación | Descargas por torrent, túneles SSH, juegos |
| **Elite** | Oculta tu IP por completo | Máxima anonimidad |
| **Anonymous** | Oculta tu IP, revela que se usa un proxy | Anonimidad equilibrada |
| **Transparent** | Revela tu IP real | Cacheo, filtrado de contenido |
